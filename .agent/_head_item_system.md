# 道具與裝備系統（關卡內）

## 1. 系統規則
- 擊殺怪物時，除了原本資源掉落外，會依怪物類型機率掉落道具/裝備。
- 道具欄位於關卡地圖下方，預設顯示 10 格。
- 點選道具格後，下方顯示該道具詳細資訊。
- 選取道具後，點擊地圖上的塔即可使用/裝備。
- 裝備限制：一座塔只能裝備 1 件裝備，且裝備後不可卸下。

## 2. 道具清單

### 2.1 消耗道具
- `等級之書`（`level_book`）
  - 效果：塔升級 1 級（若塔已滿等 Lv15 無法使用）
  - 掉落來源：水屬性怪物
  - 掉落機率：`1%`

- `速度之書`（`speed_book`）
  - 效果：塔攻擊速度 `+10%`
  - 掉落來源：木屬性怪物
  - 掉落機率：`1%`

- `力量之書`（`power_book`）
  - 效果：塔基礎傷害 `+10%`
  - 掉落來源：火屬性怪物
  - 掉落機率：`2%`

- `暴擊之書`（`crit_book`）
  - 效果：塔暴擊機率 `+10%`（上限 100%）
  - 掉落來源：輔助塔專屬升級/專精獎勵
  - 一般怪物掉落：目前無

- `建設之書`（`build_book`）
  - 效果：本次關卡建塔上限 `+1`
  - 掉落來源：Boss 擊殺額外掉落
  - 掉落機率：`10%`

### 2.2 裝備
- `潤滑油`（`lubricant`）
  - 效果：裝備塔的基礎攻擊速度改為 `1`，並保留既有倍率與天賦加成
  - 掉落來源：所有怪物
  - 掉落機率：`0.4%`

- `火力全開`（`full_firepower`）
  - 效果：裝備塔的基礎攻擊力改為 `40`，並保留既有倍率與天賦加成
  - 掉落來源：所有怪物
  - 掉落機率：`0.4%`

- `閃電鏈`（`chain_lightning`）
  - 效果：塔命中時觸發連鎖閃電
  - 參數：`20` 點閃電傷害、`20` 次連鎖、每段 `10%` 機率麻痺 `1` 秒
  - 掉落來源：所有怪物
  - 掉落機率：`0.2%`

- `勇氣旗幟`（`courage_banner`）
  - 效果：附近 `3` 格內塔的暴擊機率 `+25%`（可疊加）
  - 掉落來源：所有怪物
  - 掉落機率：`0.2%`

- `殺戮旗幟`（`slaughter_banner`）
  - 效果：附近 `3` 格內塔的暴擊傷害 `+40%`（可疊加）
  - 掉落來源：所有怪物
  - 掉落機率：`0.2%`

- `靈活旗幟`（`agility_banner`）
  - 效果：附近 `3` 格內塔的攻擊速度 `+10%`（可疊加）
  - 掉落來源：所有怪物
  - 掉落機率：`0.2%`

## 3. UI 與操作流程
1. 關卡中怪物死亡後，若觸發掉落，會直接加入道具欄堆疊數量。
2. 玩家點選道具欄中的一格，該道具會進入「待使用」狀態。
3. 玩家點地圖上的某座塔，嘗試套用效果。
4. 成功套用後，道具數量 -1；若數量歸零，自動取消選取。
5. 若條件不符（例如滿等塔使用等級之書、塔已裝備仍想裝第二件），會提示失敗原因。

## 5. 最近操作流程更新（關卡內 UI）
- 道具/裝備掉落與操作紀錄改到右下 `更新日誌 / Console` 顯示。
- Console 顯示上限為 7 行，超過時丟棄最舊訊息。
- 訊息順序為舊到新（新訊息在最下方）。
- 建塔金幣不足時，不跳對話框，改為畫面上方短暫字幕：`金錢不足`。

## 6. 後續可擴充欄位建議
- 稀有度（普通/稀有/傳說）
- 是否可堆疊、堆疊上限
- 使用目標限制（近戰塔限定、投射物塔限定）
- 裝備觸發冷卻時間
