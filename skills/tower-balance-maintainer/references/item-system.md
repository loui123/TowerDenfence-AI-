# 道具與裝備系統（關卡內）

## 1. 文件職責
- 本文件只定義道具與裝備效果、以及裝備升級規則。
- 道具掉落的【權重】與【來源怪物】以 `skills/tower-balance-maintainer/references/monster-info.md` 為主。

## 2. 道具清單

### 2.1 消耗道具
- `等級之書`（`level_book`）
  - 效果：塔升級 1 級（若塔已滿等 Lv10 無法使用）

- `速度之書`（`speed_book`）
  - 效果：塔攻擊速度 `+5%`

- `力量之書`（`power_book`）
  - 效果：塔基礎傷害 `+10%`

- `暴擊之書`（`crit_book`）
  - 效果：塔暴擊機率 `+5%`（上限 100%）

- `建設之書`（`build_book`）
  - 效果：本次關卡建塔上限 `+1`

### 2.2 裝備
- `潤滑油`（`lubricant`）
  - 效果：裝備塔的基礎攻擊速度改為 `1`，並保留既有倍率與天賦加成

- `火力全開`（`full_firepower`）
  - 效果：裝備塔的基礎攻擊力改為 `40`，並保留既有倍率與天賦加成

- `閃電鏈`（`chain_lightning`）
  - 效果：塔攻擊命中時 有40%機率觸發連鎖閃電
  - 參數：該法術會造成擊中目標基礎傷害 `1` 倍的閃電傷害，並進行 `10` 次連鎖；每次擊中目標（含連鎖擊中）有 `10%` 機率麻痺 `1` 秒（連鎖效果可與投射物的連鎖天賦或連鎖專精連動）

- `勇氣旗幟`（`courage_banner`）
  - 效果：附近 `3` 格內塔的暴擊機率 `+10% * 裝備等級`（可疊加）

- `殺戮旗幟`（`slaughter_banner`）
  - 效果：附近 `3` 格內塔的暴擊傷害 `+10% * 裝備等級`（可疊加）

- `靈活旗幟`（`agility_banner`）
  - 效果：附近 `3` 格內塔的攻擊速度 `+10% * 裝備等級`（可疊加）

## 3. 裝備升級規則
- 同一座塔若已裝備道具，再裝備「同一件裝備」時可升級。
- 非旗幟裝備可升級，最高 `Lv.5`。
- 旗幟裝備（`courage_banner`、`slaughter_banner`、`agility_banner`）可無限升級。
- 若該塔已裝備不同裝備，不能直接覆蓋裝備。
- 升級成功會顯示 `升級成功（Lv.X）`，達上限後會提示已達最高等級。

## 4. 使用規則
- 消耗道具：使用後扣除 1 個並立即生效。
- 裝備：裝備成功後綁定在該塔上，效果於戰鬥中生效。
- 道具/裝備的失敗提示統一顯示在遊戲內 Console，不使用彈窗中斷。
